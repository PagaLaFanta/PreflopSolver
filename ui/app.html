A level without sizes uses the default re-raise (3x). Giving a level sizes allows reaching it (5-bet ⇒ up to 4 raises). Sizes: 2.5bb, 3x, 75%, ai, 2.5bb+1bb (per limper), 3x+1x (per caller); several separated by commas. Each extra player in the pot multiplies the tree.

⚙ Advanced (flats / cold calls)

Default: no limit on limps/overlimps or on cold calls against the open, but none extra against 3-bets or beyond -- there only whoever closes the action calls (closing flats, see below), without new cold callers. Allowing more barely changes the EV and makes the tree much larger. Only raise these numbers if you really want to study more cold calls at some level.
